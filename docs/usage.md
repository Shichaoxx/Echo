# 使用指南

第一次使用可先跟随 [从录音到一场复盘](cookbook.md) 完成一场面试；本文用于查阅操作、设置与排错。

## 从文件夹开始

1. 运行 `./start.command`，打开终端输出的本机 URL。
2. 点击“选择文件夹”（⌘O），选择已有面试录音或录屏所在目录。默认结果保存在其下的 `echo/`；需要其他位置时，展开“转写与复盘的保存位置”。
3. 点击“保存并扫描文件夹”，打开扫描到的记录即可回放。
4. 需要逐字稿时点击“语音转文字”，先试转短对话，再提交整场任务。
5. 完成后选择版本，回听关键原文、保存笔记，再点击“交给 Codex 复盘”。

支持 MOV、MP4、MKV、WAV、MP3、M4A、WebM，扫描前文件默认需稳定 60 秒。PDF、Word 不是转写输入。扫描只登记媒体，不移动文件或自动提交转写；单文件路径导入仅作为补充入口，配置文件夹后只接受其中的原始媒体。

资料列表只显示当前文件夹。切换后原台账、转写和笔记仍保留，切回原文件夹即可继续查看。按公司、月份、自定义项目分组只改变浏览方式；删除项目只解除归属，不删除资料。

## 回放、笔记与复盘

回放不依赖逐字稿。播放按钮、进度条和时间输入可直接定位原媒体；时间输入支持秒、分:秒、时:分:秒。支持前后十秒、倍速、A–B 循环和展开录屏。转写完成后还可点击段落回听、循环当前段落，并开关跟随播放。

⌘K 打开搜索与快捷操作，⌘F 查找逐字稿。段落旁的引用按钮保存原文与时间，个人笔记自动保存在本机。若保存失败或发生并发编辑冲突，先处理提示，不要关闭含未保存草稿的页面。

“交给 Codex 复盘”先保存当前笔记，再生成当前场次、所选版本的交接内容。复制后在能读取这些本机文件的 Codex 项目中发送。Codex 完成后，刷新“Codex 复盘”查看；Echo 只读展示文档，个人笔记不会改写它。具体要求见 [Codex 复盘标准](codex-review.md)。

右侧通过“我的笔记 / Codex 复盘”页签切换；面试信息与导出位于顶部“更多”菜单。窄窗口通过侧栏和笔记按钮展开相应面板。

## 文件式 Memory

在“交给 Codex 复盘”中点击“初始化 Memory”，为当前资料库建立简短索引 `MEMORY.md`、背景与偏好模板 `profile.md` 和空 `topics/` 目录。初始化只建空模板，不分析全部面试，也不生成能力判断。之后交接会提供实际绑定路径，由用户与 Codex 维护确认后的条目。

单场 `复盘.md` 保存证据和讨论过程；`面试总结.md` 是有日期、有纳入范围的报告；Memory 保存当前确认的理解。Codex 先读索引，再选择相关的 1–3 份主题文件，必要时返回原始证据。结论须区分候选、用户确认与练习验证；当前表述可更正，稳定 ID、证据和修订历史保留。详细流程见 [Memory 使用与维护](memory.md)。

每个源文件夹有独立绑定，首次位置为当时的 `<输出根>/memory/`。同一源文件夹更改输出目录后仍使用原 Memory；切换源文件夹则使用对应绑定。不要根据新的转写路径另建第二份 Memory。当前通过文件或 Codex 阅读内容，单场复盘页签不会自动展示 Memory 或跨场总结。

## 主题

顶部主题选择器可立即切换外观；“设置与路径 → 外观与快捷键”提供主题预览，也可用 ⌘K 搜索主题名称或“切换到下一套主题”。可选跟随系统、浅色、深色，以及海盐蓝、暖砂、暮山紫、午夜蓝四套配色。

海盐蓝和暖砂采用浅色底，暮山紫和午夜蓝采用深色底。“跟随系统”只随设备切换基础浅色或深色。选择立即保存在当前浏览器；切换主题不改变媒体、逐字稿或笔记。

## 转写与队列

安装 [README](../README.md) 中的 ASR 依赖与 FFmpeg 后，选择模型、语言和范围提交。开始时间默认为 0，时长留空表示处理到结尾；术语提示可填写技术名词。

| 模型 | 时间戳与验证边界 |
| --- | --- |
| Qwen3-ASR 1.7B | 默认按最多 25 秒分块；已有本机推理验证，时间戳不是逐句或逐词对齐 |
| Whisper Turbo | 模型生成的片段时间戳；已有本机推理验证 |
| Whisper Large-v3 | 已适配，项目内端到端验证仍待完成 |

一个块可能包含双方发言。轻声、技术缩写和人名应回听核对；静音过滤可以关闭。片段试转不能支撑整场复盘，较新的结果也不一定更准确。

队列持久保存任务，推理串行运行。失败不阻塞后续任务，关闭浏览器不停止处理；电脑休眠可能影响任务。中断后需核对并重新提交，不支持半途续算。同参数的已完成结果可复用，需要重做时选择重新转写并保留旧版本。

有排队或正在转写的任务时，不能更改面试文件夹、结果输出目录或输出目录结构；等待当前任务结束，或取消尚未开始的任务后再切换。路径不变时仍可保存其他设置。

## 目录与历史资料

“设置与路径”默认展开保存位置，显示转写输出目录、当前选中面试的 Codex 复盘文件及资料库 Memory 绑定目录。复盘文件位置以服务返回值为准；未创建时显示目标位置，未选择面试时提示先选择。显示的位置对应已保存配置，修改输入框后需保存才生效。

| 用途 | 解析规则 |
| --- | --- |
| 运行数据 | `INTERVIEW_DATA_DIR`，否则源码下的 `.local/` |
| 输入 | `INTERVIEW_SOURCE_DIR` → `paths.json` → 旧 `source_path.txt`；都没有时等待用户选择 |
| 输出 | `INTERVIEW_OUTPUT_DIR` → 已保存自选输出；默认模式为已配置输入目录下的 `echo/` |

环境变量优先于保存值，调整覆盖后需重启。输入目录和自选输出的父目录须存在。Web 的“保存并扫描文件夹”保存配置并扫描；CLI 的 `paths` 只保存配置。没有输入配置时不能扫描，已有手工导入记录仍可读取。

默认保留相对目录层级：`公司A/一面/录屏.mov` 对应 `<输出根>/公司A/一面/`。后续版本放入 `versions/<版本编号>/`。可选“按公司 / 原面试文件夹归集”从目录名识别公司，未识别时归入“未分类”；已有公司层级不重复添加。该模式下，直接位于输入根的媒体以文件名建立面试目录。

扫描排除当前输出目录、输入下的 `echo/`、旧版 `echos/` 和嵌套的运行数据目录，避免把生成的回听音频再次录入。

新复盘默认定位到对应输出目录。先读取当前输出目录或原媒体同级的已有复盘；若两处都没有，再按台账中的历史转写输出位置查找，避免切换输出目录后丢失入口。一个目录有多份媒体时，以 `<媒体文件名去扩展名>.复盘.md` 区分。Codex 一律使用服务返回的 `review.path`，不要自行拼接或迁移。

更改设置不搬动旧资料。历史转写仍按台账中的路径读取；迁移需另行备份、核对文件完整性和台账路径。需要独立台账时指定独立的 `INTERVIEW_DATA_DIR`，不要把空数据目录误当成恢复后的旧资料库。

Memory 的源文件夹绑定保存在运行数据目录的 `memory-locations.json`，Memory 根目录的 `.echo-memory.json` 标记其归属。已绑定目录或关键文件缺失时，先恢复原资料；初始化不会接管未知归属的目录，也不会静默修复成空白 Memory。

## 隐私与备份

媒体、转写、笔记、复盘、真实 Memory、绑定路径、哈希、队列参数及日志都可能含私人信息，不应进入公开源码或截图。Echo 仅监听本机回环地址，使用同源会话和写入校验；没有多人账号，数据也没有应用层加密。

模型首次下载和依赖安装需要网络，本地 ASR 的推理路径不把音频发送给云端。交接内容只有在用户复制并发送给 Codex 后，才进入相应 Codex 环境；扫描或转写不会自动发送整个文件夹。

备份应包含运行数据目录、全部输出目录、原媒体、外部复盘文档，以及所有实际绑定的 Memory 目录。切换输出位置后，Memory 可能仍在旧输出根，不能只备份当前结果目录。先等待任务结束并停止服务，再复制文件；模型缓存可重新下载。Git 同步、`.gitignore` 和只切换源码版本都不能代替数据备份。

## 命令行与排错

```sh
.venv/bin/python interview.py paths
.venv/bin/python interview.py paths --source "/path/to/interviews" --output "/path/to/results"
.venv/bin/python interview.py scan
.venv/bin/python interview.py list
.venv/bin/python interview.py transcribe <ID> --start 300 --limit 180
.venv/bin/python interview.py transcribe <ID> --language zh --chunk-seconds 25
.venv/bin/python interview.py history
.venv/bin/python -m echo.memory status --data-dir "/path/to/runtime-data"
.venv/bin/python -m echo.memory init --data-dir "/path/to/runtime-data"
```

`scan --source` 与 `transcribe --output` 仅影响当前命令，不更改保存配置。同参数完成结果仍可复用；需要生成新版本时加 `--force`。

Memory 命令省略 `--data-dir` 时，使用 `INTERVIEW_DATA_DIR` 或默认 `.local/`；应与正在使用的工作台保持一致。初始化前必须明确配置源文件夹；`status` 查看绑定和警告，不创建模板。

| 现象 | 处理 |
| --- | --- |
| 地址拒绝连接 | 重新运行启动入口，以终端实际输出 URL 为准 |
| 没有媒体 | 检查所选目录、扩展名、60 秒稳定时间及排除目录 |
| 设置不生效 | 检查环境变量覆盖；有活动转写时先等任务结束 |
| 媒体无法播放 | 检查浏览器对容器和编码的支持；有转写时可使用生成的回听音频 |
| 波形或转写不可用 | 检查 FFmpeg、Python 环境与依赖；可继续使用已有资料 |
| 数据根失效 | 停止服务，核对原目录及链接，不重建空台账冒充恢复 |
| 任务失败 | 查看本机日志与版本状态，分享日志前先脱敏 |
