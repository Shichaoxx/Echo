# 归档与文件夹约定

源码、原始录屏、运行数据和人工复盘分开管理。已有录屏不要直接改名或搬家：Echo 以路径建档，移动会产生新档案。

```text
工作目录/
├── Echo/                        源码、测试、文档、启动入口
├── recordings/                  原始录屏与当场附件（可自定义）
│   └── YYYY-MM-DD_公司_岗位_轮次/
├── 私人运行数据/                 台账、模型、日志、全部转写版本
└── 面试复盘/                     通过 --destination 指定
    ├── README.md                自动生成的面试总索引
    ├── manifest.json            当前归档清单
    ├── 10_逐场面试/
    │   └── 面试名称--稳定路径标识/
    │       ├── README.md        自动生成的单场索引
    │       ├── 档案.json        台账关联与版本状态
    │       ├── 01_原始资料/      指向原录屏与附件的链接
    │       ├── 02_转写版本/      指向各完成版本的链接
    │       ├── 03_复盘/          手写复盘 + 自动生成的 Echo 笔记快照
    │       └── 04_练习/          重答、代码练习、验证记录
    ├── 20_跨场总结/              问题、行动与验证
    └── 90_归档记录/              每次独立保存 manifest 与 SQLite 快照
```

## 使用

双击 `scripts/archive.command`，或运行：

```sh
.venv/bin/python scripts/archive_interviews.py --source /path/to/recordings --destination /path/to/private-archive
```

不需要加载模型，也不会启动转写。默认沿用 `INTERVIEW_DATA_DIR` 和 `INTERVIEW_SOURCE_DIR` / `source_path.txt`；可用 `--data` 指定台账目录。默认归档到本地数据目录的 `archives/`。将绝对归档路径写入本地数据目录 `archive_path.txt` 后，双击入口会使用该路径。

新增录屏后，在 Echo 扫描并转写，再重新运行归档。未建档录屏也会出现在归档中，标记“待 Echo 扫描”；之后建档不会改变它的归档目录。可用转写版本可能只是试转，须核对参数与时间范围。

手写内容放 `03_复盘/复盘.md`、`04_练习/` 和 `20_跨场总结/`，工具不会覆盖这些文件。README、档案 JSON、manifest 和 Echo 笔记快照属于生成文件，每次更新。旧目录和旧快照不自动清理。若执行中断，修复原因后重跑；以存在 manifest.json 的历史目录作为已完成快照。

## 备份与恢复边界

SQLite 使用在线备份接口获取一致快照；归档读取快照，不修改实时数据库或任务。输出文件存在性检查发生在快照之后，因此这不是整个工作目录的原子快照。原文件链接节省空间，但不是视频或转写备份；链接内的编辑会作用于原文件。需要完整备份时，按使用指南停止任务后另行备份录屏、运行数据和人工复盘目录。

恢复数据库前停止所有 Echo 进程，保留当前数据库及其 WAL/SHM 文件的备份，再使用选定快照恢复。数据库中的源文件和转写路径仍依赖原目录位置。此工具不自动迁移、删除或恢复文件。

归档含私人路径、对话与笔记，应保存在源码仓库外或 `.local/` 内。不要提交私人归档到 Git。代码发布检查会拒绝标准归档子目录和清单。
