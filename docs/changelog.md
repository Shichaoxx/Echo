# Changelog

项目的公开历史从 `0.1.0` 开始；早期私有开发提交不作为公开历史导入。

## [1.0.0] - 2026-09-12

首个正式源码版本，运行方式为 Apple Silicon Mac 上的本地浏览器工作台。

### 修复

- 数据目录使用失效外部链接、上级目录消失或已加载数据根被移走时，阻止后台递归重建旧目录与空台账。
- 统一工作台、CLI 与后台进程的路径解析，避免子进程使用过期或不同的数据目录。
- 修正 MP3 MIME 类型；逐字稿时间戳与复盘证据支持定位回听。

### 新增

- 输入与输出目录独立配置：工作台保存目录，CLI 查看和设置，环境变量覆盖；保存与扫描分开。
- 全局队列页面、等待参数修改与审计记录；执行中的参数保持固定。
- 转写范围预览、时长校验与按面试保存的会话草稿。
- 本机个人 Profile、背景 Markdown 导出及 Codex 复盘上下文引用。
- 时间和公司分组、标签搜索、档案信息修改与可恢复归档。
- 连续逐字稿、保留上下文的搜索、片段高亮、前后 10 秒、倍速与共用播放器。
- 统一 Markdown 复盘协议，读取原存档目录的复盘、跨场总结及行动状态。
- 毛玻璃外观和主题配色完善。

### 整理与兼容性

- 业务实现集中到 `echo/`，界面组件、静态资源、测试和维护工具各自归位；原 CLI 入口保留。
- `paths.json` 保存新的路径设置，兼容旧 `source_path.txt`；默认仍为 `recordings/` 与 `.local/outputs/`。
- 目录设置不搬迁原始媒体和旧结果；台账 ID、历史转写版本与笔记保持兼容。
- 忽略外部私有数据入口，更新发布检查、架构、使用与隐私文档。
- 历史开发分支保留，正式发行编号从 `v1.0.0` 开始；本版发布源码包，原生 macOS App 在下一版本迭代。

## [0.1.0] - 2026-09-06

### Added

- Apple Silicon 本地 Qwen3-ASR 与 Whisper 模型选择。
- 增量档案、独立转写版本、回听导出与追加复盘。
- 持久 FIFO 队列、取消等待任务、去重及失败记录。
- 实时阶段与进度、自动结果更新、六套深浅主题。
- 项目说明、架构图、版本记录、隐私检查及无历史源码包。
- 无模型 CI，覆盖扫描、版本、队列和 UI 状态。

### Compatibility

- 新安装默认录屏目录为 `recordings/`；已有本机路径可由 `.local/source_path.txt` 或环境变量保留。
- GPU 推理仅面向 Apple Silicon；Qwen 当前使用块级时间戳。
