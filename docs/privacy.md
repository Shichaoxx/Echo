# 隐私边界

## 本地保存什么

源文件路径、内容哈希、音轨、转写文本、模型提示、结果版本、复盘笔记、队列状态和日志均可能含私人信息。默认保存在 recordings/ 或 .local/；自定义目录同样需要用户自行保护。数据没有应用层加密。

启动脚本仅绑定 127.0.0.1，并关闭 Streamlit 使用统计。模型首次下载访问 Hugging Face；依赖安装访问包仓库。应用的推理路径不向云端发送音频，但这不等于操作系统和所有第三方依赖绝无网络请求。

## 可以公开什么

公开代码、人工编写的通用文档、合成测试和流程图。不发布真实录屏、转写片段、笔记、日志或包含面试档案的截图。公开问题报告应使用虚构路径和合成样例。

## 当前文件不等于提交历史

删除文件或添加忽略规则不会删除 Git 历史。私有开发历史可能包含私人上下文及作者邮箱，因此初次公开应使用本项目生成的无历史发布包，在新的公开仓库初始化历史。不要直接修改原有私有仓库的可见性。

scripts/check_public.py 检查当前被跟踪文件的高风险路径、媒体、凭据特征及机器路径；--history 额外检查可达提交中的文件与提交邮箱。它只报告规则命中位置，不打印原文，不能证明不存在全部敏感信息，仍需人工审阅。

## 发布前检查

1. 当前源码扫描通过，并运行全部无模型测试。
2. 检查发布包清单，仅包含当前 Git 提交的公开文件；确认没有 .git、个人数据和模型。
3. 检查 README、Issue/PR 模板及截图是否包含真实档案。
4. 新公开仓库使用平台提供的 noreply 提交邮箱；不要推送原仓库分支或标签。
5. 若改为公开已有仓库，还须检查历史、分支、标签、PR、Issue、Release 和 Actions 附件；本地源码扫描无法覆盖它们。
