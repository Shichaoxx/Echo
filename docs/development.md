# 开发入口

这是个人项目，文档保持简单实用，不引入贡献规范、PR 模板等团队流程。使用与实现见 [README](../README.md)、[架构](architecture.md)、[隐私边界](privacy.md) 与 [版本与打包](releases.md)。

开发前检查 Git 状态。不得提交真实录屏、转写、笔记、机器路径或私人调试记录。测试使用临时目录与合成输入。界面调整不重启运行中的任务；数据库变更保持向后兼容；结果与笔记采用追加方式。

Codex 面试复盘和跨场总结遵循 [统一标准](codex-review.md)，在服务配置的原存档目录写入文档，Echo 只读展示。
